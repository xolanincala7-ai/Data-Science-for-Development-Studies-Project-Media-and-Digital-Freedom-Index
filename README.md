# Media and Digital Freedom Index (MDFI)  
*Part of my MA‑E‑Science portfolio — please read this project on .html file**

## Project Purpose  
This project develops the **Media and Digital Freedom Index (MDFI)** to measure openness of media and digital spaces across African countries. It combines indicators of press freedom, legal protections, censorship, and online privacy to capture both structural and cultural dimensions of freedom.

## Data Source  
The index is built using data from the **Ibrahim Index of African Governance (IIAG)**, which provides reliable governance and institutional indicators across African states.

## Methods  
- Tool: **R programming language** for statistical computing and index construction.  
- Approach: Normalisation of variables, aggregation into a composite score (0–100), and validation through correlation with external governance measures.  

## Results  
The MDFI proved **methodologically robust and theoretically consistent**, showing that countries with stronger legal frameworks and lower censorship scored higher, while weaknesses in privacy and impartiality reduced overall scores.
